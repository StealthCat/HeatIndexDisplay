# V7.10 — Display polish

V7.10 refines both production display targets for readability and visual hierarchy.

- Small navy cards now show the label first and the data underneath.
- Small-card labels and values use heavier rendering for better legibility.
- Station headers, apparent-temperature titles, and risk labels are emphasized.
- Metric-card borders are slightly brighter and more consistent.
- Wind, direction, and forecast cards use a clearer label/value hierarchy.
- Existing approved card geometry and the 30-second Today/Tomorrow forecast alternation are preserved.

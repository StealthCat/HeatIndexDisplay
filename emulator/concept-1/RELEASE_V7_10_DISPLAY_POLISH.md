# Emulator V7.10 — Display polish parity

This release transfers the V7.10 production display refinements into the desktop/browser emulator.

## Display changes

- Small navy metric cards now use a consistent **label above / data below** hierarchy.
- Labels and values use heavier font weights for better legibility.
- Card borders are slightly brighter and more defined.
- Station headers, apparent-temperature labels, risk labels, and footer status text use stronger weight.
- T-Display compact labels now match production (`TEMP`, `HUMIDITY`, `DEW POINT`, `VS YDAY`, `W/G MPH`, `DIR`).
- Waveshare bottom cards use clearer WIND and DIRECTION headings with larger primary values.
- Forecast cards show Today/Tomorrow and High/Low labels above the forecast values.
- Existing V7.9 provider/history/forecast behavior and 30-second Today/Tomorrow switching are unchanged.

Both production display geometries remain unchanged.

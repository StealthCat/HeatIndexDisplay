# Emulator V7.11.3 — icon alignment refinement

This is an emulator-only preview. Production firmware is unchanged.

## Both displays

Every icon in a blue metric/forecast card is now vertically centered against
the full height of its containing card.

## Waveshare 2.8

The forecast temperature line is moved upward and to the right, keeping the
large `88° / 71°` presentation while using the open forecast-card area more
naturally.

No weather-source, forecast, historical API, polling, or calculation behavior
was changed.

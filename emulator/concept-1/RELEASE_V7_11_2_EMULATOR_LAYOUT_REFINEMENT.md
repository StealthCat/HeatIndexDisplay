# Emulator V7.11.2 — emulator-only layout refinement

Production firmware is intentionally unchanged.

## LILYGO T-Display S3
All six small metric cards now follow the Dew Point card's visual rhythm:
consistent left offsets, matching label styling, matching value baselines, and
larger wind/direction values. The forecast card is unchanged.

## Waveshare 2.8
- Direction bearing is separated from the compass and centered in the remaining space.
- Cardinal direction remains centered underneath.
- Forecast high/low is a single centered `88° / 71°` string.
- Wind icon is moved down.
- `mph` is moved upward closer to the wind-speed value.

# Concept 1 — NWS-inspired Wind Chill palette

The Concept 1 hero panel now changes color dynamically in Wind Chill mode using the National Weather Service Wind Chill/Frostbite chart as its visual guide while retaining the existing dark vertical-gradient design.

The NWS chart associates frostbite danger with approximately these wind-chill thresholds:

- Above -18°F: standard Concept 1 cold blue gradient
- -18°F through -31°F: light icy-blue gradient — approximately 30-minute frostbite region
- -32°F through -47°F: deeper blue gradient — approximately 10-minute frostbite region
- -48°F and colder: purple gradient — approximately 5-minute frostbite region

The gradient background, border, warning pill, warning icon, and risk-label accent all change together. Heat Index mode retains its existing NWS HeatRisk-inspired green/yellow/orange/red/magenta palette.
